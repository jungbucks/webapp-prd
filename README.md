# webapp-prd: 수업용 웹앱 계획서 도우미

코딩을 몰라도 수업에서 쓸 작은 웹앱을 만들 수 있게 도와주는 Claude 스킬이에요.
Claude가 질문을 몇 개 하고, 그 답으로 **앱 계획서** 한 장을 만들어 보여 줘요. 선생님이 계획서를 확인하면 그대로 앱을 만들어요.

## 이런 때 쓰세요

- "복습 퀴즈 만들어 줘"
- "수업 타이머가 필요해"
- "1~30번 중에 발표자 뽑기 만들어 줘"
- "모둠 점수판 있으면 좋겠어"

인쇄용 학습지나 문서를 만들 때는 쓰지 않아요.

## 쓰는 순서

1. 만들고 싶은 도구를 말해요. "시작해 볼까?"라고만 해도 돼요.
2. Claude가 질문을 하나씩 해요. 번호만 골라도 되고, 잘 모르겠으면 "추천"이라고 하면 돼요.
   - 앱 종류(첫 말에 없을 때만) · 쓰는 장면 · 학년·과목(단원) · 기기 · 꼭 필요한 기능(최대 3개) · 화면 순서 · 느낌
3. 📋 앱 계획서를 확인하고 고칠 곳을 말해요. 넣을 문제나 단어 목록이 있으면 이때 붙여 주세요.
4. "이대로 만들어 줘"라고 하면 앱이 만들어져요.
5. 계획서를 복사해 두세요. 다음에 붙여 넣기만 해도 비슷한 앱을 바로 만들 수 있어요.

## 기본으로 지키는 것

- 로그인이나 회원가입 화면이 없어요.
- 학생 이름이나 명단은 받지 않아요. 번호 범위(예: 1~30번)나 모둠 이름·색은 괜찮아요.
- 아무것도 저장하지 않아요. 창을 닫으면 기록이 지워져요.
- 학교 인터넷에서도 열리도록 외부 사이트 없이 HTML 한 파일로 만들어요.
- 이미 있는 캐릭터(예: 펭수)는 그대로 그리지 않고, 새 마스코트로 만들어요.

## 계획서 예시

```
📋 앱 계획서
- 장면: 수업 마무리 확인 문제 (오늘 배운 내용 정리)
- 학년·과목: 고등학교 1학년 정보 – 문제 해결과 프로그래밍
- 기기: 교실 큰 화면에 띄워 다 같이
- 기능: 퀴즈를 진행해 주는 새 펭귄 마스코트
- 화면 순서: 첫 화면 → 문제 → 정답 공개 → 다음 문제 → 마무리 → 다시 하기
- 느낌: 게임처럼 (퀴즈쇼 분위기)
```

## 파일 구성

- `SKILL.md`: Claude가 읽는 스킬 본문 (질문 방식, 계획서 모양, 만드는 규칙)
- `README.md`: 사람이 읽는 설명서 (이 파일)
